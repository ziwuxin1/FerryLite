# 海外模式

配置生成器提供「人在国内」和「人在海外」两个独立表单。原国内生成器及其私人 VPS 接口保留；海外模式免费开放，不需要代码即可添加机场订阅、SOCKS5/HTTP 节点或本地导入 Mihomo YAML 节点。两种表单切换保留当前内存数据，共用已有 YAML 策略组编辑器。

海外首页只需粘贴一条 Clash / Mihomo 订阅链接，点击「下载配置」即可生成并保存；机场名自动生成。新用户默认电脑版，保留用户上次选择的设备。额外机场、独立节点、域名和分流编辑收进默认折叠的高级设置，YAML 预览只在主动展开时加载。未填写订阅且未导入节点时阻止空配置下载。私人代码入口单独保留，解锁后也可直接下载。

公开默认：中国网站、哔哩哔哩和 Steam 直连；交易所和台湾影音选台湾自动组，日本网站选日本自动组。没有对应地区的节点时不自动跨区。订阅由客户端加载，网页不代取订阅或声称验证了节点可用性；地区限定的中国内容需要用户另配回国节点。私人节点的原始默认出口优先，显式自定义设置仍最高优先。

海外分流来自用户提供的 V77：1098 条规则，涵盖中国网站、哔哩哔哩、交易所、台湾影音、日本网站、STEAM 和出口测试。规则源 `src/overseas-v77.ts` 只含分流与公共规则源，不含节点或机场账号。默认未匹配流量直连；地区节点为空时使用 REJECT，不自动改到另一地区。分类可关闭，可选择出口、补充域名，生成后可在已有编辑器中增删站点和策略组。

导出电脑和路由器两种配置，TUN 都开启。路由器沿用 V77 的 Nikki mixed 栈、auto-route=false、auto-redirect=false，由插件管理路由；电脑使用 gvisor 与自动路由。IPv6 保持关闭。DNS 使用 V77 的 1.1.1.1，控制接口仅监听本机，随机生成控制密码。

私人节点通过 `/api/overseas` 单独授权，使用生产环境 Secret：

- `FERRYLITE_OVERSEAS_CODE`：管理员指定的私人共享口令（不得写入前端）。
- `FERRYLITE_OVERSEAS_NODES_JSON`：`{version:1,nodes:[...],preferred:{策略组:[节点名称,...]}}`。由管理员原始 V77 的 proxies 和各组顺序构建，忽略 direct/reject 原语。不上传原控制密码、完整配置或其他文件。

知道私人口令的人可以领取节点；这不是绑定个人账户的登录。沿用接口的请求大小限制、同源检查、禁止缓存和每实例限频，不宣称跨实例全局限频。不要将个人节点、代码、生产响应或生成的 YAML 放入 Git 或静态部署包。

私人节点与用户添加的节点可同时存在，同名节点替换。私人模式保留 V77 的默认顺序（包括哔哩哔哩的日本出口），用户显式选择优先。订阅和所有节点凭据只保存在当前页面内存及导出文件，刷新/重置清除；localStorage 只保存独立的海外分流设置。

验证：`npm run test:overseas`、`npm run test:vps`、`npm run test:editor`、`npm run build:web`。部署整个 dist-web，含两个 api 函数；更新静态文件时不能漏掉函数。个人配置需额外使用 Mihomo 验证节点引用与协议参数。环境变量更新后重新部署才生效。
