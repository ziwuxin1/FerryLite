# Ferry 1.4.0 · YAML 配置生成器

打开直接进入生成表单，选择 PC 或 Nikki，生成后保存 YAML 并导入对应客户端。

- 移除整个状态页、已有配置导入/清除、启动前体检、出口校准、Claude 启停、IP 纯净度入口和旧配置 DNS 切换。
- 所有模式统一另存为 YAML，取消保存不写入；不再读取或更新旧版运行状态文件。旧版已导出的 YAML 和状态文件保留。
- 关闭窗口即退出，无后台托盘。
- 保留 PC / Nikki、美国独立 IP、台湾家宽交易所链路、APP 分流和生成时 DNS 设置。
- ofiii 固定默认启用；回国分类及回国节点组已移除。

## 使用

1. 选择 PC 或 Nikki，填写机场名称与 Mihomo 格式订阅链接。
2. 按需填写美国或台湾家宽代理，可导入 SOCKS 分享链接。
3. 选择 APP，点击“生成配置并另存为 .yaml”。
4. 将文件导入 Clash Verge / Mihomo 或 Nikki，启用配置并核对覆写及路由。
5. 台湾家宽首次需在“台湾-中转”选择机场台湾节点，默认拒绝连接。经代理访问 https://api4.ipify.org 可核对台湾出口。
6. ofiii 默认机场台湾；已配置台湾家宽时，可在“台湾影音”组手动切换。
