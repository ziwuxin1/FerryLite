# FerryLite 1.5.1

Windows x64 免安装版，与 FerryLite 网页共用界面、YAML 编辑器和生成核心。需要 Windows 10 / 11 和 Microsoft Edge WebView2 Runtime；程序无需安装，双击 EXE 即可运行。

## 本次更新

修复「同一订阅直接导入可用、用 FerryLite 配置则全部超时」的问题。

- **原因**：机场会更换入口域名和端口。FerryLite 通过 `proxy-providers` 引入机场，节点列表由内核缓存，原先 24 小时才刷新一次，客户端的「更新订阅」也刷新不到它。入口一换，配置里还是旧节点，日志表现为 `connect error: EOF`，所有节点超时。
- **节点列表每 10 分钟自动刷新**；内核启动或重新加载配置时，缓存超过 10 分钟也会立即重新拉取。
- **订阅拉取不再只走直连**：每个机场增加一个隐藏的「订阅更新」通道，首选直连，直连到不了订阅站点时自动改走仍可用的机场节点。
- **局域网地址直连**：`10/8`、`172.16/12`、`192.168/16` 等私有网段置于规则最前并直连。此前 TUN 模式下访问路由器、NAS、打印机等局域网 IP 会被送去机场。
- 仍需手动处理的情况：直连到不了订阅站点，同时缓存里的节点也全部失效。此时请换一个能访问订阅站点的网络，或在客户端 / 面板的「代理集合」（Proxy Providers）里手动更新。

旧版本生成的 YAML 不会自动获得以上修复，请用 1.5.1 重新生成并导入。

## 使用

1. 双击 `FerryLite-1.5.1-windows-x64.exe`。
2. 选择电脑版或路由器版，填写机场订阅，按需填写独立家宽代理。
3. 点击「生成并预览 YAML」，检查或编辑代码，然后点击「另存」选择保存位置。
4. 编辑已有配置时，进入「导入 / 编辑 YAML」，点击「选择 YAML 文件」。修改后点击「另存修改后的 YAML」。
5. 将保存的文件导入支持 Mihomo / Clash Meta 配置的 Clash 客户端或路由器插件。

关闭窗口即退出。分流草稿在本机保存；订阅地址、代理密码和未保存的 YAML 编辑不写入草稿，关闭前请另存 YAML。网页版与桌面版的本地草稿不会自动同步，可通过导出的 YAML 迁移配置。

## 文件与隐私

发布仅包含免安装 EXE 和 SHA256 校验文件。没有真实机场订阅、账号密码或预生成私人 YAML。生成和编辑在本机处理；Logo 加载会向图标服务发送站点域名。程序不安装或启动 Clash 内核，实际网络连接由用户的 Clash 客户端负责。
