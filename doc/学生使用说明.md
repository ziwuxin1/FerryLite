# Claude 一键启动器 — 学生使用说明

本软件只负责：**生成配置 → 体检链路 → 起 / 关 Claude**。
代理开关、TUN、选节点这些，仍在 **ClashMi** 里手动做。

---

## 一、准备（只做一次）

1. **装好 ClashMi**（老师给的客户端），里面带 zashboard 面板。
2. **WebView2**：Win11 一般自带；若软件打不开白屏，去微软官网装「Microsoft Edge WebView2 Runtime」。
3. **放行本软件**（未签名，属正常现象）：
   - 双击 exe 弹「Windows 已保护你的电脑」(SmartScreen) → 点**更多信息** → **仍要运行**。
   - 若杀毒软件（火绒/360/Defender）报毒拦截 → 把本 exe 加入**信任 / 白名单**后再运行。

---

## 二、首次配置（拿到独立 IP 凭据后做一次；换 IP 时重做）

你需要手头有两样东西：
- **机场订阅链接**（老师给）。
- **独立 IP 凭据**：`IP + 端口 + 用户名 + 密码`（NovProxy 一类美国静态家宽，**账密模式**）。

步骤：

1. 打开软件 → 进入「**配置生成**」页（首次自动进入）。
2. 填 5 项：
   - 机场订阅链接
   - 独立 IP server（就是那个 IP；也可填域名）
   - 端口 / 用户名 / 密码
   - 协议：默认 **socks5**；若服务商说是 http 代理就选 http（对端是 HTTPS 代理再勾上那个复选框）。
3. 点「**生成配置并另存为 .yaml**」→ 全绿后弹保存框 → 选个好找的位置（如桌面）保存。
4. **把这个 .yaml 拖进 ClashMi**（导入/添加配置文件），切换到该配置。

> 软件会把基准 IP、端口、API 信息记到本地 `config.json`，主页据此体检。

---

## 三、日常使用（每次用 Claude）

前提：先在 **ClashMi 里手动**：① 开 TUN；② 在 zashboard 把美国节点（「美国-自动」）选好；③ 配置切到上面生成的那份。

1. 打开软件 → 进入「**状态盘**」主页。
2. 点「**一键代理（体检放行）**」，软件按序检查：
   - ① ClashMi 是否在 → ② 出口 IP 是否 == 基准 IP（安全兜底）→ ③ 独立 IP 链路延迟 / 稳定性。
   - **全绿**才放行；任一红灯会给出**具体提示**，按提示在 ClashMi 里改好再点一次。
3. 绿灯后，三个启动按钮三选一：
   - **启动 Claude Code**（命令行，会新开一个黑窗口）
   - **启动桌面 App**
   - **打开网页 claude.ai**
4. 可选：「**在浏览器查看 IP 纯净度**」→ 跳 ping0.cc 肉眼确认是家宽/纯净。
5. 可选：「**测试独立 IP**」→ 复测链路延迟 / 稳定性。

---

## 四、用完关闭

点「**一键安全关闭**」：
1. 先按提示**手动关掉 claude.ai 网页**（软件杀不了某一个浏览器标签页）。
2. 勾选「我已确认 claude.ai 网页已关闭」→ 点「确认关闭」。
3. 软件会结束 Claude Code / 桌面 App 进程。**不动你的浏览器、不动 ClashMi/TUN。**

---

## 五、换 IP / 换服务商

独立 IP 到期或更换时：买到新凭据 → 回「**配置生成**」页重填那几项 → 重新生成 → 重新拖进 ClashMi。软件零改动，基准自动更新。

> 前提：新家也是「IP + 端口 + 账密」的 SOCKS5 / HTTP 代理，且是美国住宅 / 家宽 / ISP。若给的是 `ss://`/`vmess://` 或自建 VPS，需找开发者改代码。

---

## 六、红灯怎么办

| 提示 | 含义 / 处理 |
|---|---|
| 未检测到 ClashMi | 没开 ClashMi，或没加载本软件生成的配置。先把 ClashMi 打开、配置切过去。 |
| Claude 组选成了「直连」 | 在 zashboard 把 **Claude 组**改选「美国独立IP」。 |
| 「美国-自动」无可用节点 | 机场美国节点全挂或没订阅美国节点。换/刷新美国节点。 |
| 回显 IP ≠ 基准 IP（其它情况） | 节点选错 / NovProxy 未连通 / 已换 IP。检查 NovProxy 状态；换了 IP 就回「配置生成」重填。 |
| 无法检测出口 IP | ClashMi 或网络异常。检查后重试。**此时不放行，是保护你。** |

**原则：有疑问就不放行。** 宁可多检查一次，也不让你走没保护的链路。
