# FerryLite 1.5.0

Windows x64 免安装版，与 FerryLite 网页共用界面、YAML 编辑器和生成核心。需要 Windows 10 / 11 和 Microsoft Edge WebView2 Runtime；程序无需安装，双击 EXE 即可运行。

## 本次更新

- 同步网页的 Logo、界面布局、生成与导入编辑两个入口。
- 先生成并预览 YAML，再修改源码、复制或另存为；不会生成后立即强制弹保存框。
- 支持导入已有 YAML、语法检查、安全纠错、字段补全、策略组出口与域名编辑。
- 同步自定义策略组、站点补全、Logo、Reset 与本地分流草稿。
- 电脑和路由器导出选项、美国与台湾家宽代理均沿用网页当前逻辑。
- 移除可视化编辑器，不提供安装包、运行监控或代理进程管理。

## 使用

1. 双击 `FerryLite-1.5.0-windows-x64.exe`。
2. 选择电脑版或路由器版，填写机场订阅，按需填写独立家宽代理。
3. 点击「生成并预览 YAML」，检查或编辑代码，然后点击「另存」选择保存位置。
4. 编辑已有配置时，进入「导入 / 编辑 YAML」，点击「选择 YAML 文件」。修改后点击「另存修改后的 YAML」。
5. 将保存的文件导入支持 Mihomo / Clash Meta 配置的 Clash 客户端或路由器插件。

关闭窗口即退出。分流草稿在本机保存；订阅地址、代理密码和未保存的 YAML 编辑不写入草稿，关闭前请另存 YAML。网页版与桌面版的本地草稿不会自动同步，可通过导出的 YAML 迁移配置。

## 文件与隐私

发布仅包含免安装 EXE 和 SHA256 校验文件。没有真实机场订阅、账号密码或预生成私人 YAML。生成和编辑在本机处理；Logo 加载会向图标服务发送站点域名。程序不安装或启动 Clash 内核，实际网络连接由用户的 Clash 客户端负责。
